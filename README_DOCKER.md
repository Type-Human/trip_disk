# Docker Setup для Trip Disk

## Установка зависимостей

Перед сборкой Docker образа убедитесь, что установлены все зависимости:

```bash
npm install
```

## Сборка и запуск с Docker Compose

### Сборка образа

```bash
docker-compose build
```

### Запуск контейнера

```bash
docker-compose up -d
```

### Просмотр логов

```bash
docker-compose logs -f backend
```

### Остановка контейнера

```bash
docker-compose down
```

## Структура базы данных

База данных SQLite создается автоматически при первом запуске в директории `./data/trip_disk.db`.

### Таблицы:

- **trips** - путешествия
- **folders** - папки внутри путешествий
- **photos** - фотографии

### Каскадное удаление:

- При удалении путешествия автоматически удаляются все связанные папки и фотографии
- При удалении папки автоматически удаляются все связанные фотографии

## Переменные окружения

Можно настроить через переменные окружения в `docker-compose.yml`:

- `PORT` - порт сервера (по умолчанию 3000)
- `DB_PATH` - путь к файлу базы данных (по умолчанию `/app/data/trip_disk.db`)

## Volumes

- `./data` - директория с базой данных SQLite
- `./public/uploads` - директория с загруженными фотографиями

## API

После запуска контейнера API будет доступен на `http://localhost:3000/api`

Для работы с фронтендом на `http://155.212.171.181` убедитесь, что API URL настроен правильно в `.env` файле фронтенда:

```
VITE_API_URL=http://155.212.171.181/api
```
